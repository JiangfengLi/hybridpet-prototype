# Hybridpet Prototype · 宠物繁衍实验室

基于《宠物繁衍游戏_网页MVP设计文档.md》的可运行网页 MVP，同时作为实际可操作的交互原型。纯静态网页，无第三方运行时依赖，不需要 AI 密钥或数据库服务。

## 本地运行

安装 Node.js 20 或以上版本后，在项目目录运行：

```sh
npm start
```

访问 http://127.0.0.1:4173/ 。不要直接双击 `index.html`，模块加载、本地存档与跨页锁需要 HTTP 本地预览或 HTTPS 网页环境。可通过 `PORT` 环境变量调整端口。

## 已实现

- 六只起始宠物与 63 位基因配置，逐位继承、逐位 1% 突变。
- 拖放、点击、触屏与键盘投放；第二份样本放入同一格后自动繁衍。
- 样本拆解、片段重组、后代揭晓；跳过动画与减少动画。
- 25 个骨骼轮廓、8 档体型、8 色、6 种材质、12 组独立器官门控。
- 后代自动加入收藏、连续繁衍、名字修改、收藏筛选、排序、分页与双亲回看。
- IndexedDB 原子保存、刷新恢复、失败重试保持同一基因、多标签页单写入锁。
- 自生成短音效、声音设置、响应式布局与原生无障碍对话框。

原宠物始终保留。每次固定生成一只后代。相同基因组合可以重复出现，宠物个体身份独立。

## 目录

```text
dist/
  index.html        页面与对话框
  styles.css        桌面、手机与动画样式
  genes.js          基因配置、遗传、门控、起始宠物
  pet-renderer.js   基因驱动的 SVG 宠物绘制
  storage.js        本地存档及数据校验
  app.js            工作台交互、任务结算与恢复
server.mjs          本地静态文件服务器
tests/              遗传与数据规则测试
scripts/            静态检查与独立浏览器验收
交互原型说明.md      试玩流程与交互状态
```

`dist` 是直接维护的网页源码，不是需要重新生成的临时输出。部署时只需发布这个目录。`server.mjs` 只用于本地开发。

## 检查

```sh
npm test
npm run check
```

浏览器验收使用独立、临时浏览器环境，不修改玩家当前存档。安装或提供 Playwright 后设置 `PLAYWRIGHT_MODULE` 为模块路径，运行 `node scripts/browser-test.mjs`。当前工作区可使用已配置的工具运行时默认路径。浏览器脚本要求先启动本地预览，截图与结果写入未追踪的 `test-results/`。

本次实现已完成遗传与门控测试，以及三代繁衍、动画中刷新、重命名、收藏、拖放、键盘、390px 触屏、多页面接管、模拟保存失败重试等浏览器验收。

## 当前边界

能力与性格位点参与遗传，但不显示数值或产生游戏效果。AI／Tripo 3D、QTE、战斗、交易与云存档属于后续版本。本地基因不会显示在普通界面，但可通过浏览器开发工具读取，不能作为未来联网交易的可信服务端。

支持 IndexedDB、Web Locks、ES modules 的现代浏览器。数据保存在当前浏览器和网页来源中，本地预览与正式网址的存档相互独立，清除浏览器数据会清除存档。

浏览器支持 `document.modelContext` 时可注册 `list_pets` 和 `place_gene_sample`，与实际界面共享状态与操作。不支持时自动跳过，不影响游戏；真实 WebMCP 运行环境的兼容性需独立验证。
